🛠️ Les meilleurs outils de vibe coding

Le vibe coding consiste à construire un logiciel en décrivant ce que l'on veut à une IA. Voici une sélection d'outils classés par usage : de l'assistant qui écrit le code jusqu'à la mise en ligne, en passant par l'inspiration visuelle.

🤖 Coder avec une IA

Des agents qui comprennent votre projet, écrivent le code et le corrigent.

  • Claude Code (terminal, web)

    Agent de code d'Anthropic : il lit le projet, modifie les fichiers et lance les commandes.

  • Cursor (éditeur)

    Éditeur de code avec agent intégré pour écrire, déboguer et relire.

  • GitHub Copilot (éditeur, GitHub)

    Assistance et agents directement dans GitHub et les principaux éditeurs.

  • OpenAI Codex CLI (terminal)

    L'agent de code d'OpenAI, exécuté en local dans le terminal.

  • Gemini CLI (terminal, open source)

    Agent de Google pour le terminal, avec une clé d'API ou Vertex.

  • Kiro (éditeur)

    Agent d'AWS orienté spécifications et tests.

  • Cline (éditeur, open source)

    Agent pour l'éditeur et le terminal, avec accès aux fichiers, aux commandes et au navigateur.

  • Aider (terminal, open source)

    Programmation en binôme dans le terminal, compatible avec les modèles locaux, et chaque modification est enregistrée dans Git.

🚀 Prototyper une application

Décrivez votre idée, obtenez une application qui fonctionne. Idéal pour débuter.

  • Lovable (web)

    Génère des applications complètes, base de données Supabase comprise.

  • Bolt.new (web)

    Crée une application à partir d'une simple description, dans le navigateur.

  • v0 (web)

    L'outil de Vercel pour générer des interfaces React.

  • Replit (web)

    Construire, tester et héberger une application avec Replit Agent.

  • Onlook (web)

    Modifier visuellement une interface tout en travaillant sur le code.

  • Dyad (bureau, open source)

    Construire des applications en local, avec le modèle d'IA de votre choix.

🎨 Trouver l'inspiration design

De beaux exemples à montrer à votre agent pour obtenir un résultat soigné.

  • Awwwards

    Les sites primés pour leur design : la référence du web créatif.

  • Godly

    Sites sélectionnés à la main pour la qualité de leur travail graphique.

  • Minimal Gallery

    Galerie de sites haut de gamme et épurés.

  • Mobbin

    Parcours d'applications réelles, écran par écran.

  • Refero Styles

    Plus de 2 000 styles de vrais produits, typographie comprise.

  • Component Gallery

    Plus de 2 600 exemples montrant comment les grands design systems conçoivent un même composant.

  • Awesome DESIGN.md

    Des design systems décrits en Markdown, lisibles directement par votre agent.

🧩 Composants d'interface prêts à l'emploi

Des briques à copier-coller pour ne pas repartir de zéro.

  • shadcn/ui

    La référence pour des composants propres, accessibles et réutilisables.

  • Shadcnblocks

    Des sections de page complètes basées sur shadcn/ui, pas seulement des boutons.

  • 21st.dev

    Bibliothèque de composants qui se branche sur les agents via MCP.

  • Aceternity UI

    Plus de 200 composants animés React et Tailwind.

  • Magic UI

    Composants élégants pour les applications web modernes.

  • Uiverse

    Éléments d'interface créés par la communauté, en CSS et Tailwind.

  • mapcn

    Composants de cartes : marqueurs, itinéraires, info-bulles.

  • Gradient Buttons

    Une collection de boutons en dégradé, avec leur code CSS.

✨ Animations, 3D et effets visuels

Pour donner du mouvement et du relief, à utiliser avec modération.

  • Motion Primitives

    Animations et interactions prêtes à l'emploi pour React.

  • Kinetics

    Environ 150 micro-interactions, en CSS ou React, chacune livrée avec son prompt pour l'IA.

  • Anime.js

    Bibliothèque JavaScript d'animation, légère et complète.

  • Shadertoy

    Des milliers de shaders à étudier et à réutiliser.

  • 3dicons

    Bibliothèque gratuite d'icônes en 3D.

🔌 Contexte et intégrations

Donner à l'agent la documentation, les règles et l'accès aux données du projet. MCP est le protocole standard qui relie les agents à des outils.

  • Context7 (MCP)

    Fournit à l'agent la documentation à jour des bibliothèques utilisées.

  • GitHub MCP (MCP)

    Connecte l'agent aux dépôts, tickets et pull requests.

  • Supabase MCP (MCP)

    Gérer schémas, requêtes et configuration Supabase depuis l'agent.

  • Notion MCP (MCP)

    Chercher, lire et mettre à jour vos pages Notion.

  • OpenSpec

    Écrire des spécifications avant de coder, pour garder l'agent sur les rails.

🛡️ Tests, relecture et sécurité

Le code généré doit être vérifié avant d'être partagé.

  • Playwright MCP (MCP)

    L'agent pilote un vrai navigateur pour tester votre site.

  • Semgrep (MCP)

    Analyse de sécurité du code, utilisable par l'agent.

  • Prbl (web)

    Détecte les failles fréquentes dans le code écrit par une IA.

  • Qodo

    Relecture de code automatisée par IA.

  • Sentry (MCP)

    Suivre les erreurs de l'application en production et en trouver la cause.

🌍 Déployer et exécuter

Mettre le projet en ligne ou le faire tourner dans un environnement isolé.

  • Cloudflare (MCP)

    Déployer et gérer ses ressources Cloudflare depuis l'agent.

  • Publish.my (web)

    Publier un site statique directement depuis un agent.

  • E2B

    Bacs à sable sécurisés dans le cloud pour exécuter le code des agents.
